Please update the frontend with these specific changes:
1 — Exclusions preview endpoint

Old path: /api/resolve-exclusions
New path: /v1/prioritize/exclusions/preview
Request body must have two top-level fields: meta and requestData
meta needs: requestId (generate a UUID), generatedAtUtc (current timestamp), backendConsumer ("hiap-meed"), upstreamProvider ("meed-frontend"), apiContext with endpoint and locodes, totalRecords
requestData has a cityDataList array where each city has: locode, and optionally excludedSectorTags, excludedCoBenefitKeys, excludedActionsFreeText
Response comes back as results array — each city result has locode, proposedExcludedActions (each with actionId, actionName, reasons, matchedBy), exclusionSummary, and warnings

2 — Prioritization endpoint

Old path: /api/prioritize
New path: /v1/prioritize
Same meta wrapper as above
requestData has: cityDataList (required), createExplanations (boolean, default false), topN (optional integer), requestedLanguages (optional array)
Each city in cityDataList needs: locode, countryCode, cityEmissionsData (with inventoryYear and gpcData keyed by GPC reference number, each entry having a notationKey and activities array)
Optional city fields: excludedActionIds, weightsOverride, cityStrategicPreferenceSectors, cityStrategicPreferenceTimeframes, cityStrategicPreferenceCoBenefitKeys, populationSize
Response comes back as results array — each city result has locode, ranked_actions array (each with action_id, rank, final_score, impact_score, alignment_score, feasibility_score, evidence_summary, explanations), ranked_action_ids, metadata, warnings

3 — Translation endpoint

Old path: /translate
New path: /v1/explanations/translate
Same meta wrapper
requestData has: targetLanguages (array, e.g. ["es"]), rankedActions (each with actionId and canonicalExplanation), sourceLanguage (default "en")
Response has translations array — each with actionId and explanations object keyed by language code

Please also add a helper function that generates the meta object so it does not need to be repeated in every API call. Do not change any UI or display logic — only update the data fetching, request construction, and response parsing.
